# @buildbase/components

Custom business components package. This package contains custom components built on top of `@buildbase/ui` (shadcn/ui) and `@buildbase/magicui`.

## Usage

Import components from this package:

```tsx
import { CustomComponent } from "@buildbase/components/components/custom-component";
```

## Structure

- `src/components/` - Custom business components
- Components can use `@buildbase/ui` and `@buildbase/magicui` as dependencies
