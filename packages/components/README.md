# @repo/components

Custom business components package. This package contains custom components built on top of `@repo/ui` (shadcn/ui) and `@repo/magicui`.

## Usage

Import components from this package:

```tsx
import { CustomComponent } from "@repo/components/components/custom-component";
```

## Structure

- `src/components/` - Custom business components
- Components can use `@repo/ui` and `@repo/magicui` as dependencies
